# Ping Pong Game Ver. 2

Este proyecto es un sencillo juego de Ping Pong desarrollado para la web utilizando HTML5 y JavaScript puro. El objetivo es ofrecer una experiencia clásica de Pong para dos jugadores en el navegador.

## ¿Cómo jugar?
- **Jugador 1 (izquierda):** Usa las teclas `W` (arriba) y `S` (abajo) para mover la paleta.
- **Jugador 2 (derecha):** Usa las flechas `↑` (arriba) y `↓` (abajo) para mover la paleta.
- El juego inicia automáticamente al cargar la página.

## Ejecución local
1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador favorito.

¡Listo! Ya puedes jugar directamente sin necesidad de instalar dependencias.
